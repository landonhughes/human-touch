# Typography

## Goal

Typography should feel authored, legible when required, and consistent with the visual system.

## Critical text

If text must be exact and readable, prefer adding real typography with layout,
code, or design tooling rather than relying on an image model to invent it.

## Principles

Consider:

- hierarchy
- font families
- alignment
- line length
- spacing
- kerning
- contrast
- casing
- rhythm

## Respect expressive type

Experimental, oversized, distorted, kinetic, or decorative typography is valid
when explicitly part of the art direction.

Do not normalize expressive typography into generic minimalism merely for cleanliness.
