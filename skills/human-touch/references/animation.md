# Animation and Motion

## Goal

Motion should feel directed.

Animation may serve:

- state
- hierarchy
- navigation
- feedback
- physical cause and effect
- emotion
- spectacle
- narrative

Spectacle is valid when intentional.

## Common accidental problems

Watch for:

- everything moving at once
- constant idle motion
- gratuitous bouncing
- excessive springs
- particles added automatically
- unnecessary parallax
- overlong easing
- loops with no purpose
- every element entering differently

## Preserve expressive motion

If the concept explicitly calls for:

- exaggerated squash and stretch
- playful spring motion
- kinetic typography
- particle effects
- cinematic transitions
- maximalist movement

keep them and focus on coherence, timing, hierarchy, and intentionality.

## Test

Ask:

> What purpose does this motion serve?

A valid answer can be functional, emotional, narrative, or stylistic.

The problem is not decorative motion. The problem is unmotivated motion.

For pixel animation, also read [Pixel Art](pixel-art.md) to check frame
registration, pixel stability, and palette continuity. For animated 3D assets,
read [3D Modeling](3d-modeling.md) for deformation and asset checks.
