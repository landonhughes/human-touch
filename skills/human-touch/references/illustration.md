# Illustration

## Goal

Create illustration with a deliberate visual grammar.

## Define the grammar

Choose or inherit:

- line weight
- shape language
- shading approach
- texture approach
- palette philosophy
- level of abstraction
- edge treatment
- perspective rules

Then stay coherent.

## Style mixing

Combining styles is valid when deliberate.

For example, photorealistic texture plus flat vector geometry can work if the concept depends on that contrast.

Avoid accidental style drift where different objects appear to come from different visual systems.

## Simplification

Ask:

- Which details are necessary for recognition?
- Which shapes establish character?
- Which areas should remain quiet?
- Where can one mark do the work of five?

Do not add universal micro-detail merely because the generator can.
