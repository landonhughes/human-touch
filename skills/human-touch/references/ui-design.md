# UI Design and App Mockups

## Goal

Design interfaces that feel intentionally designed for a real task.

This reference can coexist with dedicated UI, product-design, or brand skills.

## Start with use

For every screen, determine:

1. What is the user trying to accomplish?
2. What is the primary action?
3. What information is necessary now?
4. What can remain hidden?
5. What state is the product currently in?
6. What happens next?

## Avoid fantasy UI by default

Unless the concept explicitly calls for it, avoid:

- meaningless dashboards
- arbitrary floating cards
- fake analytics
- decorative metrics
- excessive glass panels
- oversized empty areas
- giant numbers without context
- meaningless icons
- arbitrary rounded containers

## Respect intentional visual systems

If another design skill specifies:

- glassmorphism
- brutalism
- skeuomorphism
- dense enterprise UI
- playful consumer UI
- highly rounded cards
- minimal monochrome layout

preserve the system and apply Human Touch as quality control rather than overriding it.

## Use realistic content

Prefer believable:

- labels
- buttons
- forms
- tables
- filters
- status text
- empty states
- loading states
- errors
- confirmation states
- data density

## Minimal does not mean empty

Remove decoration before removing necessary information.
